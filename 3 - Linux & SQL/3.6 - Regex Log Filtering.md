# Regex Log Filtering

Practical regex/grep patterns used during SOC log investigation work.

## Failed login extraction
`grep -E 'Failed password.*from [0-9]{1,3}(\.[0-9]{1,3}){3}' auth.log`
Extracts failed SSH attempts along with the source IP.

## Ping sweep detection (ICMP pattern)
`grep -E '"proto":"icmp"' conn.log | grep -oE '"id\.orig_h":"[^"]+"' | sort | uniq -c | sort -rn`
Counts distinct source hosts generating ICMP traffic — flags sweep behavior 
when one host touches many destinations in a short window.

## IP extraction (generic)
`grep -oE '[0-9]{1,3}(\.[0-9]{1,3}){3}'`
Pulls every IPv4 address out of a raw log line for further correlation.
